# TOONHUB — Nike Zoom Vomero 5 3D Cinematic Hero

An ultra-luxury, high-performance E-Commerce Hero Section built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.

## ✨ Features

- **3 Cinematic 3D Perspectives**:
  - `01 // 45° Hero Profile` — Aerodynamic angled side profile
  - `02 // Top Aero Perspective` — 3D lockdown lacing & upper cage view
  - `03 // Outsole 3D Matrix` — Technical BRS 1000 carbon rubber waffle tread
- **Interactive 360° Interaction**:
  - Continuous trackpad / mouse wheel 360 rotation
  - Cursor drag & tilt parallax physics
  - Quick-switch pill navigation & keyboard arrow navigation
- **Interactive 3D Feature Hotspots**:
  - Pulsing markers directly on key sneaker technology zones with expandable technical spec cards
- **Luxury E-Commerce Suite**:
  - Interactive US Men size selector
  - Live inventory telemetry & price computation
  - Instant Add to Bag drawer toast notifications
  - High-end typography (Anton + Inter) & SVG grain texture overlay

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Run Dev Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Google Fonts (Anton, Inter)
